**Personal Finance Dashboard**
A clean, responsive web application built with React, Vite, and Tailwind CSS to track monthly spending against a custom budget.

Live Demo: https://personal-finance-dashboard-peach-pi.vercel.app/

Features

Monthly Budget Tracking: Set and update your monthly budget in Canadian Dollars (CAD).

Expense Categorization: Add expenses with specific categories (Housing, Groceries, Dining, etc.).

Visual Breakdown: Dynamic category charts showing spending percentages and totals.

Local Persistence: All data stays saved directly in your browser's local storage.

Tech Stack

Framework: React 19

Build Tool: Vite

Styling: Tailwind CSS v4

Local Development

To run this project locally on your machine:

Clone the repository:
git clone https://github.com/mrayyans10/personal-finance-dashboard.git

Navigate to the project directory:
cd personal-finance-dashboard

Install dependencies:
npm install

Start the local development server:
npm run dev
